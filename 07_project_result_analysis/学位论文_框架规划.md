## 0. 论文整体结构（对齐北邮 11 部分）

封面 → 内封 → 声明 → **摘要（中/英）** → 目录 → **符号说明** → 正文（6 章）→ 参考文献 →

**符号说明页（现在就能定稿）**：
`W` 行像素数｜`H` 帧行数｜`bpp` 像素字节数｜`L=W·bpp` 行字节数｜`F=H·L` 帧字节数｜
`f₀, T_f, T_l` 标称帧率/帧周期/行周期｜`BER` 位错误率｜`p` 单行残余失效概率｜
`p_f` 整帧含坏行概率｜`D` 往返窗口行数｜`ρ=D/H` 往返跨度比｜`h` 链路带宽余量系数｜
`τ_det, τ_bc, τ_src, τ_rt` 检出/反向通道/源响应/往返时延｜`B_src` 源端行缓存深度
